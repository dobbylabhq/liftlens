## Exercise library — exercises-dataset (ExerciseDB v1 text data)

`web/src/data/exercises.json` is generated by `scripts/build-exercises.mjs` from
https://github.com/hasaneyldrm/exercises-dataset (`data/exercises.json`).
Only text fields are used (id, name, body part, equipment, target, secondary muscles);
Chinese names, movement-pattern mappings and other annotations were added by LiftLens.
No images or animations from that repository are included — the exercise media
(© Gym visual — https://gymvisual.com/) is excluded from its MIT license and is not used here.
