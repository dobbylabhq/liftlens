# IPF 2026 判定清单（摘自 Technical Rulebook 2026 v3）

## 深蹲 §4.1
1. 起蹲与结束时膝关节锁定
2. 髋关节处大腿上表面低于膝关节顶部（程序：squat.depth_ipf）
3. 底部不得二次弹震 / 上升过程中杠铃不得下降（程序：*.downward_in_concentric）
4. 脚不得前后左右移动（程序：squat.heel_lift 可作参考）
5. 肘或上臂不得接触腿部借力

## 卧推 §4.2
1. 头、肩、臀全程接触凳面；脚全掌着地（程序：bench.hip_lift）
2. 握距两食指间 ≤ 81cm，禁止反握
3. 杠铃下放至胸或腹部并静止；**肘关节下沿与肩关节上沿齐平或更低**（程序：bench.depth_ipf）
4. 不得沉杠借弹；推起过程中整根杠不得下降
5. 结束时双肘锁定

## 硬拉 §4.3
1. 结束时膝锁定、肩后收（程序：deadlift.lockout）
2. 到达终点前杠铃不得下降
3. 不得用大腿托杠（hitching / ramping）
4. 脚不得移动

来源：ipf-2026-squat / ipf-2026-bench / ipf-2026-deadlift；关键点判定方法参考 cs231n-2024。
